# Racha Amigo

crie um app para facilitar a minha compra em grupo de produtos de gastronomia. Quero colocar um produto, o valor total da compra, o peso e as pessoas podem escolher um percentual da compra e pagar com cartão. Depois eu faço o split e pago o fornecedor. É uma compra coletiva de QUEIJO a principio.
